# 🏛️ Москва — Сердце России | Интерактивный портал

Интерактивный, высокотехнологичный презентационный веб-сайт о Москве, разработанный на **React 19**, **TypeScript** и **Tailwind CSS v4** с использованием сборщика **Vite**. Проект сочетает в себе глубокое информационное наполнение, интерактивные карты, игровые механики (перетаскивание) и премиальный дизайн с плавными 3D-анимациями.

Сайт доступен онлайн по адресу: **[https://crazy-tosser3.github.io/IThub_sites](https://crazy-tosser3.github.io/IThub_sites)**

---

## 🚀 Ключевые разделы сайта

Веб-приложение состоит из множества тематических блоков, каждый из которых представляет собой изолированный и стилизованный компонент:

1. **Приветственный экран (Hero Section)**
   * Анимированный полноэкранный заголовок с эффектом «печатающейся машинки» (динамически выводит фразу *«Сердце России»*).
   * Атмосферный фоновый визуал и плавная анимация появления элементов.

2. **Хронология истории (History Section)**
   * Интерактивный таймлайн, охватывающий ключевые исторические вехи города:
     * **1147 год**: Первое упоминание Москвы в Ипатьевской летописи (Юрий Долгорукий).
     * **1555–1561 годы**: Возведение и освящение Собора Покрова Пресвятой Богородицы (Храм Василия Блаженного) при Иване IV Грозном.
     * **Современность**: Превращение Москвы в крупнейший мегаполис Европы с населением более 13.3 млн человек.

3. **Факты и цифры (Stats Section)**
   * Интерактивная сетка в стиле **Bento Grid**.
   * Использование кастомного 3D-эффекта наклона (**Bento Tilt**): карточки динамически реагируют на положение курсора мыши, создавая ощущение объёма.
   * Отражает важные показатели: численность населения, возраст города (879 лет), лидерство в IT-сфере, количество музеев (200+) и ресторанов (2500+).

4. **Выдающиеся личности (People Section)**
   * Интерактивная галерея великих людей, чьи имена неразрывно связаны с Москвой.
   * Структурирована по ключевым категориям:
     * *Армия и Наука* (Георгий Жуков, Сергей Королёв).
     * *Общество и Культура* (Михаил Булгаков, Алексей Толстой).
     * *Экономика и Государство* (Сергей Собянин, Юрий Долгорукий, Иван III, Владимир Путин).

5. **Символика столицы (Symbols Section)**
   * Презентация официальных и неофициальных символов города: Герб со Святым Георгием Победоносцем, архитектурные шедевры Красной площади, а также исторические концепции *«Белокаменная»* и *«Третий Рим»*.

6. **Архитектурные эпохи (Architecture Section)**
   * Наглядная демонстрация эволюции облика Москвы: от Средневековой Руси (Кремль, монастыри) через барокко, классицизм и советский монументализм (Сталинские высотки) к современной архитектуре (небоскрёбы Москва-Сити).

7. **Культурные традиции (Cultural Traditions Section)**
   * Обзор праздничной жизни города: Масленица с народными гуляниями, масштабный День города, сезонные ярмарки и мультимедийный фестиваль светового шоу *«Круг света»*.

8. **Интерактивная карта достопримечательностей (Map Section)**
   * Полноценная **интерактивная карта**, которую пользователь может свободно перетаскивать (drag-and-drop) в пределах видимой области экрана.
   * На карте расположены интерактивные узлы достопримечательностей (**Кремль**, **Храм Василия Блаженного**, **Москва-Сити**).
   * При наведении на узлы плавно открываются карточки с описанием и фотографиями.

9. **Песочница филиалов IThub (IThub Section)**
   * Уникальная игровая зона-песочница с физикой перетаскивания.
   * Содержит интерактивные карточки филиалов колледжа **IThub**:
     * **Центральный филиал** (флагманский 5-этажный кампус на Курской).
     * **Северный хаб** (уютное пространство рядом с ВДНХ).
     * **Восточный кампус** (инновационная площадка с уклоном в GameDev и киберспорт).
   * Карточки можно свободно перетаскивать, бросать и перемещать по всей песочнице. При наведении на них отображается подробный очерк.

10. **Отзывы студентов (Reviews Section)**
    * Блок обратной связи, оформленный в виде интерактивных **Flip-карточек**.
    * Карточки эффектно переворачиваются на 180 градусов при наведении курсора (3D-трансформация на CSS), показывая аватар и имя студента на лицевой стороне, и развернутый содержательный отзыв — на оборотной.

11. **Умная навигация и подвал (Header, Footer, ScrollTopButton)**
    * Динамическая шапка, меняющая прозрачность и размытие фона (backdrop blur) при скролле.
    * Кнопка быстрого возврата наверх экрана, которая плавно появляется только при прокрутке страницы вниз.

## 🛠️ Технологический стек

* **React 19**: Компонентный подход, управление хуками и объектными ссылками (`useRef`).
* **TypeScript**: Полная статическая типизация всех данных, пропсов и событий.
* **Tailwind CSS v4**: Самая современная версия CSS-фреймворка. Стили полностью перенесены в инлайновые utility-классы Tailwind, обеспечивая высокую скорость рендеринга и адаптивность.
* **Vite**: Сверхбыстрая сборка и горячая перезагрузка (HMR) в процессе разработки.
* **GitHub Pages**: Автоматизированный деплой собранного бандла.

## ⚡ Уникальные технические решения и интерактив

* **`useBentoTilt`**: Измеряет координаты курсора мыши относительно размеров карточки Bento Grid, вычисляет угол наклона по двум осям (`rotateX`, `rotateY`) и плавно применяет CSS 3D-трансформацию.
* **`useDraggableMap` & `drag.ts`**: Обрабатывает события зажатия мыши или касаний экрана (touch events) на мобильных устройствах, позволяя беспрепятственно «гулять» по виртуальному холсту карты, вычисляя новые смещения (`translateX`, `translateY`) с ограничениями, чтобы карта не улетала за пределы экрана.
* **`useScrollReveal`**: Задействует API `IntersectionObserver` браузера. При прокрутке страницы блоки, попадающие в область видимости экрана, получают CSS-класс активности и плавно проявляются из прозрачности с легким сдвигом вверх.
* **Flip-эффект (3D-карточки)**: Реализован на чистом CSS с использованием свойств `perspective`, `transform-style: preserve-3d` и `backface-visibility: hidden`. Обеспечивает безупречную производительность анимации (60fps) даже на мобильных процессорах.

## ⚙️ Установка и локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/crazy-tosser3/IThub_sites.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd IThub_sites
   ```
3. Установите все необходимые npm-пакеты:
   ```bash
   npm install
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   *Сайт будет доступен по адресу `http://localhost:5173`.*

5. Сборка для продакшна:
   ```bash
   npm run build
   ```
   *Результат сборки будет помещен в директорию `dist/`.*

6. Публикация на GitHub Pages (автоматически собирает проект и заливает в ветку `gh-pages`):
   ```bash
   npm run deploy
   ```
