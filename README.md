# Москва — Столица России

Интерактивный сайт о Москве, сделанный на React и TypeScript. Проект показывает город не только как историческую столицу, но и как современный технологичный мегаполис.

## О проекте

Сайт состоит из нескольких тематических блоков:

- главный экран с анимированным заголовком;
- история Москвы от первого упоминания до современности;
- блок с фактами и цифрами о городе;
- интерактивная карта известных мест;
- раздел с филиалами IThub;
- карточка с отзывом студента.

## Достопримечательности

В проекте представлены знаковые места Москвы:

- **Кремль** — исторический центр столицы и один из главных символов России;
- **Храм Василия Блаженного** — узнаваемый архитектурный памятник XVI века на Красной площади;
- **Москва-Сити** — современный деловой район с небоскрёбами и технологичной атмосферой.

Эти локации показаны в формате интерактивных карточек: пользователь может навести курсор, прочитать краткое описание и взаимодействовать с элементами на карте.

## Филиалы колледжа

На сайте также есть отдельный блок, посвящённый филиалам IThub:

- **Центральный филиал** — основной кампус в центре города;
- **Северный хаб** — филиал рядом с ВДНХ;
- **Восточный кампус** — пространство с акцентом на GameDev и современные цифровые направления.

Карточки филиалов можно перетаскивать по экрану, а при наведении открывается дополнительная информация и изображение кампуса.

## Особенности

В проекте есть несколько интерактивных элементов:

- плавное появление блоков при прокрутке;
- изменение шапки сайта при скролле;
- кнопка быстрого возврата наверх;
- карточки, которые можно перетаскивать;
- раскрывающиеся описания локаций;
- переворачивающаяся карточка отзыва.

## Технологии

Проект написан с использованием:

- React;
- TypeScript;
- CSS;
- Vite.

Основная логика и структура находятся в `src/App.tsx`, стили — в `src/App.css` и `src/index.css`, изображения — в `public/img/`.
